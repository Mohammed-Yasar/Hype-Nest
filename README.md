HypeNest 🧢👟

A Full-Stack Marketplace for Hype & Streetwear Products

 Live Demo: https://hype-nest.vercel.app/

 Overview

HypeNest is a full-stack web application that enables users to discover, list, and manage hype and streetwear products such as sneakers, apparel, and collectibles. The platform focuses on product discovery, seller transparency, and user engagement, inspired by modern resale marketplaces.

This project was built end-to-end to gain hands-on experience with real-world full-stack development, including authentication, database design, API development, and modern frontend UX patterns.

Key Features

User authentication with JWT

Product listing with image uploads

Marketplace feed with search, filters, and sorting

Seller profiles and dashboards

Favorites (wishlist) and view tracking

Admin approval workflow for listings

Responsive, information-dense UI with modern UX patterns

Tech Stack
Frontend

TypeScript

Tailwind CSS

Axios

Backend

Node.js

Express.js

MongoDB (Mongoose)

JWT Authentication

Deployment

Frontend: Vercel

Backend: Render

Database: MongoDB Atlas

Design & Engineering Highlights

Modular REST API design with role-based access control

Clean separation between frontend and backend

Graceful handling of empty states, loading states, and errors

Scalable data models for products, users, and engagement metrics

UI designed to be compact, intuitive, and production-like

Scope & Tradeoffs

Payments and real-time chat were intentionally excluded to keep the project focused on marketplace discovery and seller-buyer interaction design

Product images are used for demonstration purposes only

Some engagement features are simulated to represent early-stage marketplace behavior
